1 概述
隔空科技自主研发的 AT6010 60GHz 雷达 SOC 芯片支持通过 UART 接口和上位机进行通
信，包括基本功能命令，FMCW 配置命令和调试指令等。本文主要介绍了 AT6010 的通信协
议格式和各命令说明。
2 通信协议定义
通信协议的帧数据主要分为发送帧数据和回复帧数据，发送帧为上位机给 AT6010 SOC
发送控制命令的帧数据格式，回复帧为 AT6010 SOC 执行完上位机控制的指令后回复给上位
机的帧数据格式。详细的帧数据格式描述如下。
2.1 发送帧数据格式
发送帧主要为上位机通过 UART发送给 AT6010 芯片的帧数据，其格式定义如下：
Description：
Head: 发送帧帧头，值为 0x58；
Control Frame Payload: 发送帧有效负荷，分命令分组，控制命令，参数长度和参数：
CMD Group: 命令分组，3 个有效位，最多支持 7 个分组的命令；
CMD: 控制命令，5 个有效位，即一个分组最多支持 32 条控制指令；
Parameter Length: 参数的总长度（字节）；
Para_0 ~ Para_n: 参数（长度由 Parameter Length指定）
Check Code: 校验码，值为前面数据的和：
Check Code = Head + Payload_0 + … + Payload_n

SOC 芯片执行控制命令后的回复数据，回复数据帧格式定义如下：

3 命令说明
3.1 基本命令
3.1.1 设置感应电平持续时间
功能说明：
当雷达感应到运动物体时，OUT PIN 信号输出有效电平持续时间，若 OUT配置为 PWM
模式时，则为输出 PWM 持续时间。
指令码：0x4
参数：para1: time(low byte), para2: time(high byte); In seconds
发送命令格式（HEX）：58 04 02 Byte0 Byte1 xx xx (xx xx 表示发送帧/回复帧校验码,以下同理)
回复帧：参考回复帧格式
e.g., set time to 1s
Send: 58 04 02 01 00 5F 00
Resp: 59 04 01 00 5E 00 (success). Other: fail.
3.1.2 获取感应电平持续时间
功能说明：
获取雷达芯片/模块雷达感应的有效电平持续时间。

3.1.3 设置光敏阈值
功能说明：
设置雷达芯片/模块光敏感应的阈值，只有硬件支持光敏并且软件打开该功能时有效。
指令码：0x6
参数：para1: lux(low byte), para2: lux(high byte)
发送命令格式（HEX）：58 06 02 Byte0 Byte1 xx xx
回复帧：参考回复帧格式
e.g., set lux to 1000
Send: 58 06 02 E8 03 4B 01
Resp: 59 06 01 00 60 00 (success). Other: fail.

功能说明：
获取雷达芯片/模块光敏感应的阈值，只有硬件支持光敏并且软件打开该功能时有效。
指令码：0x7
参数：none
发送命令格式（HEX）：58 07 00 5F 00
回复帧：参考回复帧格式
e.g., get lux, the result value is 0x03E8
Send: 58 07 00 5F 00
Resp: 59 07 02 E8 03 4D 01
3.1.5 保存雷达设置
功能说明：
主要将设置的参数（感应距离、OUT 信号持续时间、光敏阈值、雷达打开/关闭状态和
波特率）保存在模块的 Flash 中，重新开机将加载上次设置的参数值。由于命令交互和芯片
内部 flash 写入时间较长，如果需要将参数保存在雷达模块中，建议发送命令后延迟 1 秒以

上再发送其它命令。
指令码：0x8
参数：para1: 0x1 (保存), 0x0 (不保存)
发送命令格式（HEX）：58 08 01 01 62 00 (保存)
58 08 01 00 61 00 (不保存)
回复帧：59 08 01 00 62 00 (success). Other: fail.
3.1.6 获取雷达保存状态
功能说明：
获取设置的参数（感应距离、OUT 信号持续时间和光敏阈值）是否已保存。若设置参数
但没有发送保存雷达设置命令而直接关机，设置的参数在下次启动时不会生效。
指令码：0x9
参数：none
发送命令格式（HEX）：58 09 00 61 00
回复帧：59 09 01 01 64 00 // e.g., save is on
59 09 01 00 63 00 // e.g., save is off
3.1.7 设置 OUT信号状态
功能说明：
若 OUT 配置为 IO 时，设置 OUT PIN 为高电平或低电平，若 OUT配置为 PWM 模式时，
则设置是否输出 PWM 信号。
指令码：0xA
参数：para1: 0x1 (设置 OUT 有效), 0x0 (设置 OUT无效)
发送命令格式（HEX）：58 0A 01 01 64 00 (设置 OUT有效)
58 0A 01 00 63 00 (设置 OUT无效)
回复帧：59 0A 01 00 64 00 (success). Other: fail
3.1.8 设置 PWM占空比
功能说明：
当 OUT 配置为 PWM 模式时，可通过该命令设置 PWM 输出的占空比。
指令码：0xB
参数：para1: value of duty (low byte), para2: value of duty (high byte). Unit 0.1%
发送命令格式（HEX）：58 0B 02 Byte0 Byte1 xx xx
回复帧：参考回复帧格式
e.g., set duty to 50.0%
Send: 58 0B 02 F4 01 5A 01

3.1.9 System Reset
功能说明：
系统复位，发送该命令后，系统将重启复位。
指令码：0x13
参数：para1: reset mode (uint8)
发送命令格式（HEX）：58 13 01 01 6D 00
回复帧：根据波特率不同，回复的数据有所差异
59 13 01 00 6D 00 ...(success). Other: fail.
(...代表 uart0 在芯片 reset 过程中的数据输出)

3.1.11波特率切换
功能说明：

Resp: 59 19 01 00 73 00 (success). Other: fail.

3.4 主动上报命令
ULP 应用主动上报检测结果，以数据流的形式上报，格式和 CI 相似，但有细微差别。
其格式约定如下：
1. 所有字段都是 little-endian 格式；
2. HEAD 固定为 0x5A；
3. LEN 表示后面 PAYLOAD 字段占据字节个数；
4. CHECK 是 8 比特校验和，计算内容包括：HEAD, LEN, PAYLOAD 三部分；
5. 每种 TYPE 对应的结构体不同，其中 F0, F1, …, FM 分别对应其结构体一个字段；

例如 htm = 1868 mm = 0x074C，status=3，reserved=0，字节流如下图所示：
LEN = 1 + 2 + 2 = 5
F0 表示结构体中第一个字段，这里表示 htm , 0x074C，小端模式为 4C, 07；
F1 表示结构体中第二个字段，这里表示 status , 0x03；
F2 表示结构体中第三个字段，默认 reserved 一直为 0；
CHECK 校验和 = 5A + 05 + 01 + 4C + 07 + 03 = B6
