MS60-1211S80M 60G 雷达 · 本板接线约定
================================

【注意】2026-07-26 实时网表尚未按下列脚序连接（U6/U7 左右功能对调且电源脚与 OUT 对调）。
改图完成前禁止 1:1 对插模组。以下为正确目标接法。

座子（2mm 1×3P）
  U6 左：1=GPIO-OUT，2=GND，3=VCC
  U7 右：1=TX（模组发），2=GND，3=RX（模组收）

电源
  推荐：5V → 负载开关 → RADAR_VCC → U6-3
  去耦：RADAR_VCC 旁 100nF + 10µF → GND
  也可直接 3V3/5V（无开关时固件总开关只停采集，不断电）

通断控制（推荐）
  SGM2551（C699876）：VIN=5V，VOUT=RADAR_VCC，EN←XL9555 IO0_1（高=开）
  或 AO3401 高边 + 3.3V→栅极电平转换（勿 3.3V 直驱 5V 栅）
  关断时固件停止驱动 UART TX，防灌电

信号
  GPIO-OUT → U6-1 → XL9555 IO0_0（Radar-OUT）
  TX       → U7-1 → U1 IO9（ESP RX）
  RX       → U7-3 → U1 IO10（ESP TX）
  UART：115200 8N1；TX/RX 交叉

不要接
  T2（RXD0/TXD0）下载口
  U1 IO35/36/37

调试
  /radar；固件总开关默认只暂停采集，加负载开关后才可真正断电
